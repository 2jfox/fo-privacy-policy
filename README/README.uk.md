## Вступ

Forum App («ми», «наш» або «додаток») поважає вашу конфіденційність і прагне захищати ваші персональні дані. Ця політика конфіденційності пояснює, як ми обробляємо інформацію, коли ви користуєтеся нашим мобільним додатком.

## Інформація, яку ми збираємо

### 1. Дані паспорта/ID-картки через NFC
- **Що ми збираємо**: коли ви скануєте свій паспорт або ID-картку за допомогою NFC, мы зчитуємо:
  - Особисту інформацію (ім'я, дата народження, громадянство, номер документа)
  - Терміни дії документа
  - Біометричну фотографію з чипа документа
  - Дані MRZ (машинозчитуваної зони)

- **Як ми її використовуємо**: ці дані використовуються виключно для:
  - Верифікації особи всередині додатка
  - Відображення вашої інформації для функцій голосування/участі
  - **Важливо**: ці дані обробляються локально на вашому пристрої та НЕ передаються автоматично на наші сервери

### 2. Дані камери
- **Що ми збираємо**: доступ до камери для сканування MRZ.
- **Як ми її використовуємо**: тільки для обробки OCR (оптичного розпізнавання символів) у режимі реального часу для читання MRZ паспорта.
- **Зберігання**: зображення обробляються в оперативній пам'яті й не зберігаються.

### 3. Інформація про акаунт
- **Що ми збираємо**:
  - Токени автентифікації
  - Налаштування користувача
  - Історію голосування та дані про участь

### 4. Технічна інформація
- **Що ми збираємо**:
  - Інформація про пристрій (модель, версія ОС)
  - Версія додатка
  - Звіти про збої та дані про продуктивність

## Зберігання та безпека даних

### Локальне зберігання
- Дані паспорта шифруються та зберігаються локально з використанням AsyncStorage.
- Біометричні дані (фотографії) зберігаються в зашифрованому форматі.
- Дані паспорта не передаються без явних дій користувача.

### Серверне зберігання
- Тільки підтвердження верифікації особи (а не необроблені дані паспорта).
- Записи про голосування та історія участі.
- Налаштування акаунта.

### Заходи безпеки
- Наскрізне шифрування (E2EE) для передачі даних.
- Закріплення сертифікатів (Certificate pinning) для міжмережевої взаємодії з API.
- Відсутність незашифрованого трафіку (cleartext) у робочих (production) збірках.
- Безпечне зберігання з використанням Android Keystore.

## Обмін даними

Ми **НЕ**:
- Продаємо вашу особисту інформацію.
- Передаємо дані паспорта/ID третім особам.
- Зберігаємо державні ідентифікаційні номери на наших серверах.
- Використовуємо ваші біометричні дані для будь-яких цілей, крім верифікації.

Ми **МОЖЕМО** передавати:
- Анонімізовану статистику голосування для публічної прозорості.
- Інформацію, яка вимагається правоохоронними органами за законними офіційними запитами.

## Ваші права

Ви маєте право на:
- **Доступ**: запросити копію ваших персональних даних.
- **Видалення**: запросити видалення вашого акаунта та пов'язаних із ним даних.
- **Виправлення**: оновити неправильну інформацію.
- **Експорт**: отримати свої дані в переносному форматі.
- **Відмову**: вимкнути певні функції, які обробляють персональні дані.

## NFC та сканування паспортів

### Спеціальне повідомлення про сканування паспортів
- Читання паспорта через NFC вимагає фізичного доступу до вашого документа.
- Дані зчитуються з використанням безпечних стандартів ICAO.
- Протоколи BAC/PACE забезпечують безпеку зв'язку.
- Ви повинні вручну ввести дані MRZ, щоб розблокувати NFC-чип.
- Дані паспорта ніколи не залишають ваш пристрій без недвозначної згоди.

### Обмеження цілей використання
Сканування паспорта використовується ВИКЛЮЧНО для:
- Перевірки особи користувача для визначення права на голосування.
- Запобігання створенню дублікатів акаунтів.
- Забезпечення принципу «одна людина — один голос».

## Використання камери

Камера використовується виключно для:
- Сканування тексту MRZ з паспортів.
- Обробки OCR у режимі реального часу.
- Знімки не робляться і не зберігаються.

## Терміни зберігання даних

- **Локальні дані паспорта**: зберігаються доти, доки ви не вийдете з системи або не видалите додаток.
- **Дані акаунта на сервері**: зберігаються протягом 2 років після останньої активності.
- **Записи про голосування**: зберігаються постійно для забезпечення прозорості (в анонімізованому вигляді).

## Конфіденційність дітей

Наш сервіс не призначений для користувачів молодше 18 років. Ми навмисно не збираємо особисту інформацію про дітей.

## Міжнародна передача даних

Ваша інформація може передаватися та оброблятися в країнах, відмінних від вашої країни проживання. Ми забезпечуємо наявність належних гарантій безпеки.

## Зміни до Політики конфіденційності

Ми можемо періодично оновлювати цю політику конфіденційності. Ми повідомлятимемо вас про будь-які зміни шляхом:
- Оновлення дати «Останнє оновлення».
- Сповіщень у додатку про значні зміни.
- Запиту згоди при внесенні суттєвих змін.

## Сторонні сервіси

Ми використовуємо такі сторонні сервіси:
- **Google Play Services**: для дистрибуції додатка та ML Kit (OCR).

- **JMRTD**: бібліотека з відкритим вихідним кодом для читання паспортів (обробляє дані локально).

## Правова основа для обробки (GDPR)

Ми обробляємо персональні дані на підставі:
- **Згоди**: для сканування паспорта та біометричних даних.
- **Договору**: для надання послуг голосування та участі.
- **Юридичних зобов'язань**: для дотримання чинного законодавства.
- **Законних інтересів**: для забезпечення безпеки та запобігання шахрайству.

Резиденти Каліфорнії мають додаткові права відповідно до CCPA, включаючи:
- Право знати, яка особиста інформація збирається.
- Право на видалення особистої інформації.
- Право на відмову від продажу (ми не продаємо особисті дані).
- Право на недискримінацію.

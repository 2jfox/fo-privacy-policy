## Информация, которую мы собираем

### 1. Данные паспорта/ID-карты через NFC
- **Что мы собираем**: когда вы сканируете свой паспорт или ID-карту с помощью NFC, мы считываем:
  - Личную информацию (имя, дата рождения, гражданство, номер документа)
  - Сроки действия документа
  - Биометрическую фотографию с чипа документа
  - Данные MRZ (машиносчитываемой зоны)

- **Как мы её используем**: эти данные используются исключительно для:
  - Верификации личности внутри приложения
  - Отображения вашей информации для функций голосования/участия
  - **Важно**: эти данные обрабатываются локально на вашем устройстве и НЕ передаются автоматически на наши серверы

### 2. Данные камеры
- **Что мы собираем**: доступ к камере для сканирования MRZ.
- **Как мы её используем**: только для обработки OCR (оптического распознавания символов) в режиме реального времени для чтения MRZ паспорта.
- **Хранение**: изображения обрабатываются в оперативной памяти и не сохраняются.

### 3. Информация об аккаунте
- **Что мы собираем**:
  - Токены аутентификации
  - Пользовательские настройки
  - Историю голосования и данные об участии

### 4. Техническая информация
- **Что мы собираем**:
  - Информация об устройстве (модель, версия ОС)
  - Версия приложения
  - Отчеты о сбоях и данные о производительности

## Хранение и безопасность данных

### Локальное хранение
- Данные паспорта шифруются и хранятся локально с использованием AsyncStorage.
- Биометрические данные (фотографии) хранятся в зашифрованном формате.
- Данные паспорта не передаются без явного действия пользователя.

### Серверное хранение
- Только подтверждения верификации личности (а не необработанные данные паспорта).
- Записи о голосовании и история участия.
- Настройки аккаунта.

### Меры безопасности
- Сквозное шифрование (E2EE) для передачи данных.
- Закрепление сертификатов (Certificate pinning) для межсетевого взаимодействия с API.
- Отсутствие незашифрованного трафика (cleartext) в рабочих (production) сборках.
- Безопасное хранение с использованием Android Keystore.

## Обмен данными

Мы **НЕ**:
- Продаем вашу личную информацию.
- Передаем данные паспорта/ID третьим лицам.
- Храним государственные идентификационные номера на наших серверах.
- Используем ваши биометрические данные для каких-либо целей, кроме верификации.

Мы **МОЖЕМ** передавать:
- Анонимизированную статистику голосования для публичной прозрачности.
- Информацию, требуемую правоохранительными органами по законным официальным запросам.

## Ваши права

Вы имеете право на:
- **Доступ**: запросить копию ваших персональных данных.
- **Удаление**: запросить удаление вашего аккаунта и связанных с ним данных.
- **Исправление**: обновить неверную информацию.
- **Экспорт**: получить свои данные в переносимом формате.
- **Отказ**: отключить определенные функции, обрабатывающие персональные данные.

## NFC и сканирование паспортов

### Специальное уведомление о сканировании паспортов
- Чтение паспорта через NFC требует физического доступа к вашему документу.
- Данные считываются с использованием безопасных стандартов ICAO.
- Протоколы BAC/PACE обеспечивают безопасность связи.
- Вы должны вручную ввести данные MRZ, чтобы разблокировать NFC-чип.
- Данные паспорта никогда не покидают ваше устройство без явного согласия.

### Ограничение целей использования
Сканирование паспорта используется ИСКЛЮЧИТЕЛЬНО для:
- Проверки личности пользователя для определения права на голосование.
- Предотвращения создания дубликатов аккаунтов.
- Обеспечения принципа «один человек — один голос».

## Использование камеры

Камера используется исключительно для:
- Сканирования текста MRZ с паспортов.
- Обработки OCR в режиме реального времени.
- Снимки не делаются и не сохраняются.

## Сроки хранения данных

- **Локальные данные паспорта**: хранятся до тех пор, пока вы не выйдете из системы или не удалите приложение.
- **Данные аккаунта на сервере**: хранятся в течение 2 лет после последней активности.
- **Записи о голосовании**: хранятся постоянно для обеспечения прозрачности (в анонимизированном виде).

## Конфиденциальность детей

Наш сервис не предназначен для пользователей младше 18 лет. Мы намеренно не собираем личную информацию о детях.

## Международная передача данных

Ваша информация может передаваться и обрабатываться в странах, отличных от вашей страны проживания. Мы обеспечиваем наличие надлежащих гарантий безопасности.

## Изменения в Политике конфиденциальности

Мы можем периодически обновлять настоящую политику конфиденциальности. Мы будем уведомлять вас о любых изменениях путем:
- Обновления даты «Последнее обновление».
- Уведомлений внутри приложения о значительных изменениях.
- Запроса согласия при внесении существенных изменений.

## Сторонние сервисы

Мы используем следующие сторонние сервисы:
- **Google Play Services**: для дистрибуции приложения и ML Kit (OCR).
- **React Native**: фреймворк приложения.
- **JMRTD**: библиотека с открытым исходным кодом для чтения паспортов (обрабатывает данные локально).
